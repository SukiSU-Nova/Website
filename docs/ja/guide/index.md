# はじめに

SukiSU-Nova へようこそ。Android デバイス向けに高度なカーネルベースの Root 管理を提供する次世代の Android Root ソリューションです。

## SukiSU-Nova とは？

SukiSU-Nova は、Android デバイス専用に設計されたモダンで安全かつ強力な Root ソリューションです。強化されたセキュリティ機能と高い互換性を備えた、カーネルレベルの Root アクセス管理を提供します。

## 主な特徴

### 🔒 カーネルベースの su と Root アクセス管理
カーネルレベルで安全に Root アクセスを管理し、従来のソリューションに比べて優れたセキュリティとパフォーマンスを実現します。

### 📱 App Profile
制御された環境内に Root 権限を閉じ込めることができる、高度なアプリケーションプロファイリングシステムです。

### 🔧 幅広いデバイスサポート
非 GKI / GKI 1.0 デバイスのサポートを復活させ、旧世代の Android デバイスとの互換性を確保しています。

### ⚙️ 豊富なカスタマイズ性
ニーズに合わせて Root 体験を細かく調整できる、包括的なカスタマイズオプションを備えています。

### 🔌 KPM カーネルモジュール対応
高度なカーネル改変や機能拡張のための KernelPatch Module（KPM）機能をフルサポートしています。

## SukiSU-Nova を選ぶ理由

- **セキュリティ第一**：高度なセキュリティ機能でデバイスとデータを保護
- **モダンな設計**：最新の Android セキュリティモデルを見据えたアーキテクチャ
- **高い互換性**：GKI・非 GKI の両方のデバイスに対応
- **活発な開発**：最新の Android バージョンに合わせて継続的にアップデート
- **コミュニティ主導**：オープンソースで活発なコミュニティによるサポート

## システム要件

SukiSU-Nova をインストールする前に、デバイスが以下の要件を満たしていることを確認してください：

- **Android バージョン**：Android 8.0（API 26）以上
- **ブートローダー**：アンロック済み
- **リカバリ**：カスタムリカバリ（TWRP 推奨）
- **ストレージ**：100MB 以上の空き容量
- **知識**：Android の改造に関する基本的な知識

## 安全上の注意

::: danger 重要
⚠️ **デバイスの Root 化は保証対象外となる可能性があり、手順を誤ると回復不能な損傷を引き起こす恐れがあります。**

必ず以下を守ってください：
- 作業前に完全なバックアップを作成する
- デバイスに互換性があることを確認する
- 手順を慎重に確認して進める
- 復旧手段をあらかじめ用意しておく
:::
