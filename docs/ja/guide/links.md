## 🔧 プロジェクトとビルド

SukiSU と SUSFS をベースにコンパイルされたプロジェクト：

### GKI ビルド
::: tip 汎用 GKI サポート
KernelSU と SUSFS を統合した Generic Kernel Image ビルド
:::

**リポジトリ：** [GKI_KernelSU_SUSFS](https://github.com/ShirkNeko/GKI_KernelSU_SUSFS) または [GKI_KernelSU_SUSFS](https://github.com/WildKernels/GKI_KernelSU_SUSFS)

### OnePlus ビルド
::: tip デバイス専用ビルド
MKSU と SUSFS を組み込んだ OnePlus 向け自動カーネルビルド
:::

**リポジトリ：** [Action-Build](https://github.com/Numbersf/Action-Build) · メンテナー：[Numbersf](https://github.com/Numbersf)

> 元のプロジェクトは非推奨となりました。
