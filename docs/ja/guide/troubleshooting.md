# トラブルシューティング

## マネージャーアプリをアンインストールするとデバイスが固まる

マネージャーアプリのアンインストール中にデバイスがハングする場合は、`com.sony.playmemories.mobile` もあわせてアンインストールしてください。

## それでも解決しない場合

1. [互換性](./compatibility)ページを確認してください。
2. [リポジトリ](https://git.zako.shirkneko.top:20004/shirkneko/SukiSU/issues)で既存の Issue を検索するか、新しく Issue を作成してください。
3. [Telegram コミュニティ](https://t.me/sukiksu)で質問してください。

::: tip
問題を報告する際は、マネージャーアプリからエクスポートしたバグレポート（設定 → ログを報告）を添付してください。
:::
