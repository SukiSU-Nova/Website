# App Profile

App Profile では、SukiSU-Nova が各アプリをどのように扱うか（Root の使用可否、使用時の実行権限、モジュールの可視性など）を制御できます。プロファイルはマネージャーアプリで管理します。

## プロファイルの種類

すべてのアプリには次の 3 つのプロファイル状態のいずれかが設定されます：

| 種類 | 意味 |
|------|------|
| **デフォルト** | 特別な処理を行わず、グローバル設定に従います。 |
| **テンプレート** | 複数のアプリ間で共有できる再利用可能な設定セット（*テンプレート*）を使用します。 |
| **カスタム** | アプリごとに個別の設定を行います。 |

## 設定項目

プロファイルは次の項目で構成されます。

### マウント名前空間

アプリが Root 権限で実行されたときに参照するマウント名前空間を制御します。

- **継承**：呼び出し元プロセスの名前空間を引き継ぎます。
- **グローバル**：グローバル名前空間を使用します。
- **個別**：アプリ専用のプライベート名前空間を割り当てます。

### グループとケーパビリティ

- **グループ**：アプリプロセスが所属する Linux グループ。
- **ケーパビリティ**：アプリプロセスに付与される Linux ケーパビリティ。

アプリが実際に必要とする権限のみを付与してください。

### フラグ

- **no_new_privs**：この Root プロファイルのコンテキスト内から SukiSU-Nova 経由でさらなる権限昇格を行うことを防ぎます。

### SELinux コンテキスト

- **ドメイン**：アプリプロセスが実行される SELinux ドメイン。
- **ルール**：このプロファイルに対して追加で適用される SELinux ポリシールール。

### モジュールのアンマウント

有効にすると、このアプリから見える範囲でモジュールによって変更されたファイルが元の状態に復元されます。モジュールの変更を認識させたくないアプリに対して使用してください。

## テンプレート

テンプレートは名前付きの再利用可能なプロファイルです。マネージャーでは次の操作が行えます：

- テンプレートの**作成**および**編集**（それぞれ ID、名前、説明を持ちます）。
- テンプレートが適用されているアプリの**確認**。
- クリップボードからのテンプレートの**インポート**およびクリップボードへの**エクスポート**による共有。

::: tip
複数のアプリで同じ設定が必要な場合は、アプリごとに個別設定するのではなく、テンプレートを 1 つ作成してすべてのアプリに適用してください。
:::

::: warning
グループ、ケーパビリティ、SELinux ルールの設定を誤ると、アプリが正常に動作しなくなったり、デバイスのセキュリティが低下したりする可能性があります。動作しなくなった場合は、そのアプリを**デフォルト**に戻してください。
:::
