# インストールガイド

このガイドでは、Android デバイスに SukiSU-Nova をインストールするための手順を詳しく説明します。手順をよく確認しながら進めてください。

## 事前準備

始める前に、以下が揃っていることを確認してください：

- [ ] 対応デバイスであること。詳しくは[互換性ガイド](./compatibility.md)をご確認ください。
- [ ] ブートローダーがアンロック済みであること。
- [ ] TWRP などのカスタムリカバリがインストールされていること。
- [ ] カスタム ROM やカーネルのフラッシュに関する基本的な知識。
- [ ] デバイスのカーネルソース、または互換性のあるビルド済みカーネル。

## インストール方法

デバイスや好みに応じて、いくつかのインストール方法があります。

### 方法 1：マネージャー経由で LKM をインストール（推奨） {#method-1-lkm-via-the-manager-recommended}

LKM モードでは、SukiSU-Nova をローダブルカーネルモジュールとしてインストールします。マネージャーがデバイスの KMI に一致するビルド済みモジュールで boot イメージにパッチを適用するため、自分でカーネルをビルドする必要はありません。

#### 手順：

1.  **マネージャーのインストール**：[リリースページ](https://git.zako.shirkneko.top:20004/shirkneko/SukiSU/releases)から最新の `SukiSU_*.apk` をダウンロードしてインストールします。
2.  **インストーラーの起動**：ホーム画面のインストールカード（**タップしてインストール**）をタップします。
3.  **boot イメージの提供方法を選択**：
    -   **直接インストール（推奨）**。
    -   **ファイルを選択してパッチ**：boot イメージを選択します。マネージャーはデバイスに該当するパーティション（`boot`、`init_boot`、または `vendor_boot`）のイメージを推奨します。**純正イメージとしてバックアップ**を有効にする場合は、選択したイメージが純正イメージであることを確認してください。
    -   **ファイルをダウンロードしてパッチ**：フル OTA イメージまたはファクトリーイメージの URL を入力します。マネージャーがその中から `boot`、`init_boot`、または `vendor_boot` パーティションを探します。
    -   **ローカルの LKM ファイルを使用**：同梱のモジュールではなく独自のモジュールを使用します。`.ko` ファイルのみ対応しています。
4.  **KMI の選択**：マネージャーにデバイスの KMI（*このデバイスの KMI バージョン*）が表示されます。選択を求められた場合は一致するものを選択してください。
5.  **フラッシュして再起動。**

::: tip ビルド済み LKM イメージ
リリースビルドには次の KMI 向けのビルド済みモジュールが同梱されています（それぞれ aarch64 および x86_64 対応）：`android12-5.10`、`android13-5.10`、`android13-5.15`、`android14-5.15`、`android14-6.1`、`android15-6.6`、`android16-6.12`、`android17-6.18`。最新の一覧は[最新リリース](https://git.zako.shirkneko.top:20004/shirkneko/SukiSU/releases/latest)をご確認ください。
:::

::: warning ジェイルブレイクモード
**ジェイルブレイクモード**では、ブートローダーがロックされたデバイスのパーティションを書き換えると AVB（Android Verified Boot）が破損し、デバイスが起動できなくなる可能性があります。
:::

### 方法 2：ビルド済み GKI パッケージを使用

Xiaomi、Redmi、Samsung などの多くの Generic Kernel Image（GKI）2.0 搭載デバイスで推奨される方法です。[^1]

[^1]: この方法は、Meizu、OnePlus、Realme、OPPO のようにメーカーがカーネルに大幅な独自変更を加えているデバイスには適していません。

#### 手順：

1.  **GKI ビルドのダウンロード**：[リンク集](./links.md)からデバイスのカーネルバージョンに適した GKI ビルドを探し、ファイル名に `AnyKernel3` を含む `.zip` ファイルをダウンロードします。
2.  **リカバリ経由でフラッシュ**：
    - [ ] デバイスを TWRP リカバリで起動します。
    - [ ] 「Install」を選択します。
    - [ ] ダウンロードした `AnyKernel3` zip ファイルを選択します。
    - [ ] スワイプしてフラッシュを実行します。
    - [ ] フラッシュが完了したらシステムを再起動します。
3.  **インストールの確認**：
    - [ ] SukiSU-Nova マネージャーアプリをインストールします。
    - [ ] アプリを開き、Root アクセスが正常に有効化されているか確認します。
    - [ ] デバイスの設定画面からも新しいカーネルバージョンを確認できます。

::: details ファイル形式ガイド
サフィックスなしの `.zip` アーカイブは非圧縮です。`.gz` サフィックスは特定モデル向けの圧縮形式を示します。
:::

### 方法 3：OnePlus デバイス向けカスタムビルド

OnePlus デバイスの場合は、カスタムビルドを作成する必要があります。

#### 手順：

1.  **デバイス情報の収集**：以下が必要です：
    -   カーネルバージョン（例：`5.10`、`5.15`）。
    -   プロセッサのコードネーム。
    -   OnePlus オープンソースカーネルリポジトリのブランチと設定ファイル。
2.  **カスタムビルドの作成**：[リンク集](./links.md)のリンクを使用して、デバイス情報をもとにカスタムビルドを生成します。
3.  **ビルドのフラッシュ**：
    - [ ] 生成された `AnyKernel3` zip ファイルをダウンロードします。
    - [ ] リカバリで起動します。
    - [ ] zip ファイルをフラッシュします。
    - [ ] 再起動してインストールを確認します。

### 方法 4：手動カーネル統合（上級者向け）

この方法は、ソースからカーネルをビルドする上級ユーザー向けです。

#### 統合スクリプト：

-   **Main ブランチ（LKM）**：
    ```sh [bash]
    curl -LSs "https://git.zako.shirkneko.top:20004/shirkneko/SukiSU/raw/branch/main/kernel/setup.sh" | bash -s main
    ```
-   **Builtin ブランチ**：
    ```sh [bash]        
    curl -LSs "https://git.zako.shirkneko.top:20004/shirkneko/SukiSU/raw/branch/main/kernel/setup.sh" | bash -s builtin
    ```

::: warning 必須カーネル設定
KPM サポートには `CONFIG_KPM=y` を有効にする必要があります。
非 GKI デバイスの場合は、さらに `CONFIG_KALLSYMS=y` と `CONFIG_KALLSYMS_ALL=y` も有効にする必要があります。
:::

## インストール後の設定

### OTA アップデート後に Root を維持する

OTA（Over-the-Air）アップデート後も Root アクセスを維持するには、==再起動する前に==以下の手順を実行してください。

1.  **非アクティブスロットへフラッシュ**：
    - [ ] OTA アップデートのダウンロードとインストールが完了したら、**再起動しないでください**。
    - [ ] SukiSU-Nova マネージャーを開きます。
    - [ ] フラッシュ / パッチ画面に移動します。
    - [ ] `AnyKernel3` カーネル zip ファイルを選択します。
    - [ ] 非アクティブスロットへのインストールを選択します。
    - [ ] フラッシュ完了後、安全に再起動できます。
2.  **LKM モード（推奨）**：OTA インストール後、再起動する前に[方法 1](#method-1-lkm-via-the-manager-recommended)のインストーラーを起動し、**未使用スロットにインストール（OTA 後）** を選択します。

::: tip
非 GKI デバイスの場合、OTA 後に Root を維持する最も安全な方法は TWRP で再度カーネルをフラッシュすることです。
:::

## 動作確認チェックリスト

インストール後、以下の項目を確認してください：

- [ ] **マネージャーアプリ**：SukiSU-Nova マネージャーアプリが開き、Root ステータスが正常に表示される。
- [ ] **Root アクセス**：Root チェッカーアプリで Root アクセスが機能していることを確認できる。
- [ ] **カーネルバージョン**：`設定 > デバイス情報` のカーネルバージョンに SukiSU-Nova カーネルが反映されている。

## トラブルシューティング

問題が発生した場合：

1.  [互換性ガイド](./compatibility.md)を再度確認してください。
2.  [リポジトリ](https://git.zako.shirkneko.top:20004/shirkneko/SukiSU)で Issue や解決策を確認してください。
3.  [Telegram コミュニティ](https://t.me/sukiksu)に参加してリアルタイムでサポートを受けてください。

::: danger 安全に関する注意
⚠️ **必ずバックアップを取ってください！** 万が一に備えて元の `boot.img` のコピーを保管し、デバイスを復旧できるよう準備しておいてください。
:::
