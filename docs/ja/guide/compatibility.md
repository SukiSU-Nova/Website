# 互換性ステータス

::: tip GKI 2.0 デバイス
GKI 2.0 カーネル（5.10+）を搭載した Android デバイスに対応しています。マネージャーを使い、デバイスの KMI に一致するビルド済みモジュールで LKM としてインストールできます。詳しくは [LKM インストール](./installation#method-1-lkm-via-the-manager-recommended)をご覧ください。
:::

::: warning レガシーカーネルのサポート
旧世代のカーネル（4.4+）も互換性がありますが、カーネルを手動でビルドする必要があります。詳しくは[統合ガイド](./how-to-integrate)をご覧ください。
:::

::: tip 拡張互換性
SukiSU-Nova は追加のバックポートにより 3.x カーネル（3.4〜3.18）もサポートできます。これは実験的な機能です。
:::

## アーキテクチャ対応状況

現在、以下のプロセッサアーキテクチャをサポートしています：

| アーキテクチャ | サポートレベル | 備考 |
|----------------|----------------|------|
| **arm64-v8a** | ✅ フルサポート | 主要ターゲットアーキテクチャ |
| **armeabi-v7a** | ✅ 基本サポート | 最小限の動作機能 |
| **Riscv64** | 🟡 一部サポート | 一部デバイスで対応 |
| **X86_64** | 🟡 一部サポート | 一部デバイスで対応 |
